# Nathan Godly Portfolio

A responsive portfolio website built with plain HTML, CSS, and JavaScript.

## Open the website
Extract the ZIP and open index.html in your browser. No installation or build step is needed.

## Edit the website
Open index.html in VS Code or another text editor. Page content is in the HTML, styling is in the <style> block, and the expandable project details use the <script> block.

## Host the website
Upload index.html to a static website host. All styling, scripts, and the favicon are included in the file; no external assets are required.
